# THE ALPHA GYM — Luxury website

A responsive Next.js 14 static-export website for The Alpha Gym, Patel Nagar, Kashipur.

## Features
- Cinematic dark / metallic-gold visual direction and animated editorial typography.
- Scroll-reveal sections, responsive navigation and image hover motion.
- Six distinct supplied photo assets in the gallery; no cartoon athlete or generated 3D gym scene.
- Real gym contact actions: phone, WhatsApp and Google Maps.
- Membership enquiry CTA; pricing is intentionally not invented.
- Static export for Cloudflare Pages (`out`).

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
The static site is exported to `out/`.

## Cloudflare Pages
See [DEPLOY-CLOUDFLARE.md](./DEPLOY-CLOUDFLARE.md).

## Before client launch
Confirm permission to use all supplied photographs, replace any sample/reference athlete image with gym-approved photography if needed, and add a real gym workout video supplied or licensed by the owner. The included files do not fabricate a video or claim stock footage is from this gym.
